# NucDPosIt

**NucDPosIt** — открытый Python-пакет для определения позиций нуклеосом по данным секвенирования с использованием моделирования стохастической активности экзонуклеазы ExoIII и вероятностного EM-алгоритма. Алгоритм ориентирован на построение физически согласованных карт позиционирования нуклеосом, пригодных для дальнейшего мезомасштабного моделирования фибрилл хроматина.

## Основные особенности

* **Моделирование активности ExoIII:** учитывает стохастическую природу расщепления/ограничения фрагментов при обработке экзонуклеазой ExoIII (в частности, на данных MNase-seq / MNase-seq-exoIII).
* **Вероятностный EM-алгоритм:** применяет обучение без учителя на основе смеси распределений и стохастический Expectation-Maximization (EM) для оценки позиций нуклеосом путем оптимизации функции правдоподобия.
* **Физическая согласованность карт:** получаемые карты позиционирования проверяются на отсутствие стерических коллизий при 3D / мезомасштабном моделировании нуклеосомных фибрилл.

## Архитектура и принцип работы

1. **Модуль моделирования ExoIII** — описывает стохастический профиль сигнала и неопределенность границ фрагментов, возникающую при ферментативной обработке.
2. **Модуль стохастического EM** — итеративно уточняет параметры смеси и координаты нуклеосом по функции правдоподобия, формируя согласованную карту позиций.

## Установка

Клонируйте репозиторий и установите зависимости (рекомендуется использовать отдельное виртуальное окружение Python):

```bash
git clone https://github.com/intbio/NucDPosIt.git
cd NucDPosIt
pip install -e .
```

> **Примечание:** Уточните актуальный список зависимостей в `requirements.txt` или `pyproject.toml` перед установкой.

## Быстрый старт

Пример использования в Python-скрипте:

```python
from nucdposit import NucDPosIt

# Инициализация и запуск моделирования позиций
model = NucDPosIt()
positions = model.fit_predict("path/to/input_reads.bam")
```

Запуск через CLI (если предусмотрен в вашей сборке):

```bash
nucdposit --input path/to/data --output path/to/positions.bed
```

## Входные и выходные данные

* **Входные данные:** профили покрытия или координаты фрагментов из экспериментов типа MNase-seq / MNase-seq-exoIII.
* **Выходные данные:** предсказанные координаты нуклеосом и сопутствующие оценки правдоподобия, готовые для анализа и 3D-моделирования хроматина.

## Валидация и применение

Алгоритм разработан и протестирован на экспериментальных данных для *S. cerevisiae* (наборы MNase-seq и MNase-seq-exoIII). Полученные карты проверялись с помощью мезомасштабного моделирования нуклеосомных фибрилл в **PYNAMOD** для контроля отсутствия стерических перекрытий между нуклеосомами.
