# NucDPosIT

**Nucleosome Dyad Position Identification Tool**

NucDPosIT — программный комплекс для определения положений диад нуклеосом по данным парноконцевого секвенирования. В основе метода лежит вероятностная модель ферментативного расщепления нуклеосомной ДНК и стохастический алгоритм Expectation-Maximization (EM), позволяющий восстанавливать положения нуклеосом на основании экспериментально полученных фрагментов ДНК.

В отличие от традиционных методов анализа позиционирования нуклеосом, основанных на поиске локальных максимумов в усреднённых профилях заселённости хроматина, NucDPosIT анализирует отдельные секвенированные фрагменты и оценивает вероятность их принадлежности различным положениям диад.

Такой подход позволяет исследовать неоднородность позиционирования нуклеосом и выявлять альтернативные положения диад, которые могут не проявляться в усреднённых профилях.

---

Алгоритм состоит из двух основных этапов:

1. **ExoModel** — оценка вероятностного распределения расстояний, на которых ферментативное расщепление заканчивается вследствие диссоциации фермента от ДНК.
2. **EMModel** — определение положений диад нуклеосом с использованием полученного распределения вероятностей и стохастического алгоритма Expectation-Maximization.

На первом этапе восстанавливается модель ферментативного расщепления ДНК. На втором этапе эта модель используется для определения положений диад, наиболее вероятным образом объясняющих наблюдаемые экспериментальные фрагменты.

## 2. Математическая модель

### 2.1. Оценка вероятностей диссоциации фермента (ExoModel)

Первый этап заключается в восстановлении распределения вероятностей диссоциации фермента на основании экспериментального распределения длин ДНК-фрагментов.

В основе модели лежит предположение, что два независимых фермента взаимодействуют с противоположными концами нуклеосомной ДНК. Каждый фермент последовательно расщепляет ДНК до момента своей диссоциации.

Обозначим через \(P(d)\) вероятность того, что фермент диссоциирует после расщепления участка ДНК длиной \(d\).

При условии независимости двух процессов расщепления экспериментальное распределение длин фрагментов может быть описано свёрткой двух одинаковых распределений:

\[
H(l) = \sum_{i=0}^{l} P(i)P(l-i),
\]

где:

- \(H(l)\) — вероятность получения фрагмента длиной \(l\);
- \(P(i)\) — вероятность диссоциации фермента после расщепления участка длиной \(i\).

Для восстановления исходного распределения вероятностей используется оптимизация функции потерь, учитывающей отклонение экспериментального распределения от теоретического, а также регуляризацию.

В результате ExoModel позволяет получить оценку вероятностей диссоциации фермента для различных расстояний от края нуклеосомной ДНК.

Для выбора коэффициента регуляризации предусмотрен поиск по заданному диапазону значений.

**Результат:** распределение вероятностей диссоциации фермента, сохраняемое в файле `errors.csv`.

### 2.2. Определение положений диад нуклеосом (EMModel)

На втором этапе восстановленное распределение вероятностей используется для определения положений диад нуклеосом.

Для каждого экспериментального фрагмента с координатами начала \(L\) и конца \(R\) рассчитывается вероятность его возникновения при заданном положении диады \(D\):

\[
P(L,R \mid D) =
P(D-L+1)\cdot P(R-D+1).
\]

Таким образом, вероятность наблюдения фрагмента определяется совместной вероятностью двух независимых процессов расщепления ДНК с противоположных сторон нуклеосомы.

Для анализа используется смесь вероятностных распределений, соответствующих различным кандидатным положениям диад.

Параметры смеси оптимизируются с помощью стохастического алгоритма Expectation-Maximization:

- **E-step:** вычисление апостериорных вероятностей принадлежности каждого фрагмента различным положениям диад.
- **M-step:** стохастическое перераспределение фрагментов между компонентами смеси и обновление положений диад.
- **Регуляризация:** контроль сложности модели и подавление слабо поддерживаемых компонент.

Алгоритм также предусматривает объединение совпадающих положений диад и удаление компонент с пренебрежимо малыми весами.

Анализ генома выполняется последовательно по отдельным геномным окнам.

**Результат:** таблица с координатами экспериментальных фрагментов, назначенными положениями диад и вероятностями соответствия фрагментов этим положениям.

## 4. Установка

Для работы NucDPosIT необходим Python версии 3.9 или выше.

### Клонирование репозитория

```bash
git clone https://github.com/USERNAME/NucDPosIT.git
cd NucDPosIT
```

### Создание окружения

В репозитории находится файл `env/requirements.txt`, содержащий экспорт спецификации Conda-окружения.

Для воспроизведения окружения:

```bash
conda create --name nucdposit --file env/requirements.txt
conda activate nucdposit
```

**Примечание:** файл `requirements.txt` представляет собой экспорт Conda-окружения для Linux-64, а не стандартный список зависимостей для pip. Для использования на других платформах может потребоваться отдельная установка и проверка совместимости зависимостей.

## 5. Использование

Работа с NucDPosIT предполагает последовательное выполнение двух основных этапов.

### 5.1. Восстановление распределения вероятностей диссоциации фермента

На первом этапе анализируется распределение длин экспериментальных ДНК-фрагментов из BAM-файла.

Запуск:

```bash
python scripts/exomodel.py input.bam \
    --output-dir exomodel_results \
    --start 1 \
    --end 50 \
    --npoints 20 \
    --njobs 8
```

Основные параметры:

| Параметр | Описание | Значение по умолчанию |
|---|---|---|
| `bam_file` | Путь к входному BAM-файлу | Обязательный |
| `--output-dir` | Директория для результатов | `./exomodel_results` |
| `--start` | Нижняя граница диапазона коэффициентов регуляризации | `1` |
| `--end` | Верхняя граница диапазона коэффициентов регуляризации | `50` |
| `--npoints` | Количество проверяемых значений регуляризации | `10` |
| `--njobs` | Количество параллельных процессов | `1` |
| `--reg_coef` | Фиксированный коэффициент регуляризации | `None` |
| `--no-plots` | Отключение построения графиков оптимизации | `False` |

Если параметр `--reg_coef` не задан, выполняется поиск оптимального коэффициента регуляризации в указанном диапазоне.

Пример структуры выходной директории:

```text
exomodel_results/
│
├── errors.csv
├── optimization_results.png
│
└── fit_plots/
    ├── fitplot1.0.png
    ├── fitplot2.0.png
    └── ...
```

Основной результат — `errors.csv`, содержащий восстановленные распределения вероятностей для исследованных коэффициентов регуляризации.

Дополнительно сохраняются графики оптимизации и сравнения экспериментального распределения длин фрагментов с распределением, восстановленным моделью.

### 5.2. Определение положений диад нуклеосом

На втором этапе запускается EMModel, который использует BAM-файл с координатами экспериментальных фрагментов и распределение вероятностей, полученное на предыдущем этапе.

Пример запуска:

```bash
python scripts/nucdposit.py input.bam \
    exomodel_results/errors.csv \
    10 \
    --out_dir nucdposit_results \
    --window_size 3000 \
    --dyad_dist 80 \
    --nfits 50 \
    --device cuda
```

Здесь `10` — пример значения коэффициента регуляризации, которое должно соответствовать одной из строк в `errors.csv`.

Основные параметры:

| Параметр | Описание | Значение по умолчанию |
|---|---|---|
| `alignment_path` | Путь к BAM-файлу с координатами фрагментов | Обязательный |
| `errorpath` | Путь к файлу с распределениями вероятностей диссоциации | Обязательный |
| `lamb` | Коэффициент регуляризации для выбора распределения из `errors.csv` | Обязательный |
| `--regions_path` | BED-файл с областями генома для анализа | `None` |
| `--out_dir` | Директория для результатов | `./nucdpst_res` |
| `--window_size` | Размер анализируемого геномного окна | `3000` |
| `--step` | Шаг перемещения окна | `window_size - 300` |
| `--dyad_dist` | Начальное расстояние между кандидатными диадами | `80` |
| `--nfits` | Количество запусков оптимизации | `50` |
| `--device` | Устройство для вычислений (`cpu` или `cuda`) | `cuda` |
| `--min_iter` | Минимальное количество итераций | `100` |
| `--max_iter` | Максимальное количество итераций | `500` |
| `--tol` | Критерий сходимости | `0.01` |
| `--alpha` | Коэффициент скользящего среднего | `0.1` |
| `--reg_coef` | Коэффициент регуляризации EM-модели | `1` |
| `--temperature_coef` | Температурный коэффициент EM | `20` |
| `--accept_chromo` | Список хромосом для анализа | `None` |
| `--except_chromo` | Список хромосом, исключаемых из анализа | `None` |

### 5.3. Результаты анализа

В процессе работы геном разбивается на последовательные окна. Для каждого окна выполняется независимая оптимизация модели.

Результаты сохраняются в TSV-файл:

```text
nucdposit_results/
│
├── input.log
└── input_dpst.csv
```

Основные столбцы итоговой таблицы:

| Столбец | Описание |
|---|---|
| `start` | Начальная координата экспериментального фрагмента |
| `stop` | Конечная координата экспериментального фрагмента |
| `dyads` | Координата назначенной диады нуклеосомы |
| `template\|dyad` | Максимальная апостериорная вероятность соответствия фрагмента назначенной диаде |
| `ref` | Название хромосомы |
| `batch_i` | Индекс анализируемого окна |
| `qid` | Идентификатор экспериментального фрагмента |

Таким образом, для каждого экспериментального фрагмента сохраняются его исходные координаты и соответствующее оценённое положение диады.

## 6. Запуск на вычислительном кластере (SLURM)

Для обработки больших геномных данных предусмотрена возможность параллельного выполнения анализа на вычислительных кластерах с использованием планировщика SLURM.

Файл:

```text
scripts/slurm_nucdposit.py
```

обеспечивает автоматическое распределение хромосом между вычислительными заданиями, отправку заданий в очередь SLURM, отслеживание их выполнения и объединение результатов.

Пример структуры запуска:

```bash
python scripts/slurm_nucdposit.py \
    --njobs 4 \
    --nucdposit_params '{"alignment_path":"input.bam","errorpath":"errors.csv","lamb":10,"out_dir":"results","device":"cuda","window_size":3000}' \
    --slurm_params '{"time":"24:00:00","cpus_per_task":8,"mem":"16G","gres":"gpu:1"}'
```

Основные параметры:

- `--njobs` — количество параллельных заданий;
- `--nucdposit_params` — JSON-словарь параметров EMModel;
- `--slurm_params` — JSON-словарь параметров SLURM.

Каждое задание обрабатывает отдельную группу хромосом. После завершения вычислений результаты отдельных заданий автоматически объединяются в один файл.

Дополнительные bash-скрипты для запуска вычислений находятся в директории `slurm/`.

## 7. Основные возможности

NucDPosIT предоставляет следующие возможности:

- Восстановление вероятностного распределения ферментативного расщепления нуклеосомной ДНК.
- Использование физически обоснованной модели взаимодействия ферментов с ДНК.
- Определение положений диад на основании индивидуальных экспериментальных фрагментов.
- Вероятностное распределение фрагментов между кандидатными положениями диад.
- Выявление альтернативных положений диад в рамках модели смеси.
- Регуляризация модели для контроля количества определяемых компонент.
- Обработка геномных данных по отдельным окнам.
- Вычисления с использованием CPU и CUDA.
- Параллельная обработка хромосом с использованием SLURM.

## 8. Ограничения и особенности

Результаты работы NucDPosIT зависят от качества исходных данных и корректности оценки распределения вероятностей диссоциации фермента.

Для получения воспроизводимых результатов рекомендуется:

- Использовать корректно сформированные BAM-файлы с парными выравниваниями.
- Использовать согласованные экспериментальные данные для оценки распределения диссоциации и определения положений диад.
- Подбирать коэффициенты регуляризации с учётом характеристик конкретного эксперимента.
- Контролировать сходимость модели и устойчивость результатов при изменении параметров оптимизации.
- Учитывать влияние размера геномного окна на результаты анализа.
